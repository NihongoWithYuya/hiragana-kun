# ひらがなくん / Hiragana-kun

これから日本語を始める人のための、ひらがな・カタカナ学習サイトです。
画面上部の「ひらがな / カタカナ」で切り替えます（カタカナを直接開く URL: `…/hiragana-kun/?kata`）。
**五十音表**からどの文字にも入れて、**書き順をアニメーションで見て**、そのまま**なぞり書き**で練習できます。
UI は英語（学習者が読めるように）、練習する文字はかなです。

**公開ページ → https://nihongowithyuya.github.io/hiragana-kun/**

## できること

| | 機能 | 内容 |
|---|---|---|
| 1 | 五十音表 | 清音46／濁音・半濁音25／小さい仮名4／拗音33 をタップで選択。カタカナは＋伸ばし棒「ー」と外来語の音21（ファ ティ ヴ…） |
| 2 | 書き順アニメ | 光る線が1画ずつ伸びる。1画送り/戻し・ゆっくり再生あり |
| 3 | なぞり書き | 指・マウスでなぞる。書き始めの位置と向きが違うと書かせない |
| 4 | 発音 | 先生の録音108本（音声合成は使わない）。カタカナは同じ音なのでひらがなの録音を再生 |
| 5 | クイズ | かな→ローマ字／ローマ字→かな／音声→かな の3種・10問。カタカナは見間違いやすい字（シ/ツ、ソ/ン…）を選択肢に混ぜる |
| 5b | そっくり文字 | 間違えた組み合わせ（シ↔ツ、い↔り…）を記録して「苦手ペア」を判定。2択の Look-alikes ドリル、間違えた瞬間に2文字を並べて書き順アニメ＋見分け方を表示 |
| 6 | 進捗 | 覚えた文字が光る。ひらがな・カタカナ別々に localStorage に保存 |

なぞり書きの判定は「書き出しの位置・書き順・線をなぞり切ったか」の3点だけを見ます。
きれいさの採点はしません（初学者がつまずくのは順番と向きなので）。

拗音（きゃ等）は2文字の組み合わせなので、書き順アニメと音声のみ。
なぞり書きは「き」「ゃ」それぞれの文字に飛んで練習します。

## デザイン

ダーク＆グロウ。濃紺の背景に、光る線で文字が書かれます。
書き順アニメが一番映えること、他のひらがな学習サイトと見た目がかぶらないことを狙っています。
なぞっている線はピンクの光、完成した線は白＋アクアの光。

## 構成

```
index.html               アプリ本体（CSS・JS 埋め込み、依存ライブラリなし）
kana-data.js             かな表（ひらがな KANA_TABLES／カタカナ KATAKANA_TABLES。index.html と録音スタジオで共用）
stroke-data.js           書き順データ（自動生成・CC BY-SA 3.0）
audio/<codepoints>.m4a   先生の録音（例: あ → 3042.m4a、きゃ → 304d-3083.m4a、ファ → 30d5-30a1.m4a）
audio/raw/               録音の元ファイル（webm）。配信には不要
audio/manifest.js        録音済みの一覧（自動生成）
tools/record.html        録音スタジオ
tools/build_audio.py     raw の録音を整音して m4a と manifest を作る
tools/build_strokes.py   KanjiVG から書き順データを取得する
```

`index.html` をダブルクリックするだけでも（`file://` でも）動きます。
スマホで確認するときは `python3 -m http.server` で配信してください。

## 音声の録り方

音声合成は使いません（単音を機械に読ませると発音の見本にならないため）。
**録音済み: ひらがな 108/108**（`audio/*.m4a`、計約0.9MB、1本0.24〜0.60秒）。
カタカナの基本音（ア〜ピョ）はひらがなと同じ音なので、ひらがなの録音をそのまま鳴らします。
**カタカナの外来語の音: 録音済み 21/21**（ファ フィ フェ フォ ティ ディ トゥ ドゥ デュ ウィ ウェ ウォ シェ ジェ チェ ヴァ ヴィ ヴ ヴェ ヴォ ツァ。1本0.41〜0.58秒）。
録音がない文字は LISTEN が「RECORDING SOON」になり、音声クイズには出ません。

```bash
python3 -m http.server 8765          # プロジェクト直下で
open http://localhost:8765/tools/record.html   # Chrome で開く
```

1. 「保存先フォルダを選ぶ」で `audio/raw` を選択（Chrome のみ。他のブラウザだと1件ずつダウンロード）
2. 表示されたかなを1文字ずつ読む。**スペースキー**で録音開始／停止、録れたら自動で次へ
3. 全部録れたら整音とマニフェスト生成:

```bash
python3 tools/build_audio.py         # 無音カット＋音量そろえ＋m4a化
```

長さが極端な録音は「CHECK THESE」として一覧に出るので、そこだけ録り直してください。
整音は「前後の無音カット→ラウドネス統一（-16 LUFS）→リミッター」。
無音カットのしきい値は固定ではなく、ファイルごとの環境音レベルに合わせて決めています。
固定しきい値だと「ひゃ・ひゅ・ひょ」の息の音（母音より30dB小さい）が丸ごと削られ、きゃ行に聞こえてしまいます。

カタカナの外来語の音を録るときは `?set=foreign` を付けます（21個だけが並ぶ）。録ったら同じく `build_audio.py`:

```
open "http://localhost:8765/tools/record.html?set=foreign"
```

特定の文字だけ録り直すときは `?only=` を付けると、その文字だけが並びます:

```
open "http://localhost:8765/tools/record.html?only=ひ,ふ,ほ,ひゃ,ひょ"
```

録音ページの「🔊 今サイトで鳴る音」で、書き出し済みの音を聞いてから録り直せます。
`audio/raw/` は録音の原本なので、消さずに残しておくと後から録り直さずに再調整できます。
録音は静かな部屋で、口から20cmほど離して、0.5〜1秒。108ファイルで10〜15分ほどです。

## 書き順データの再生成

```bash
python3 tools/build_strokes.py    # → stroke-data.js を上書き
```

標準ライブラリのみ。157文字（ひらがな75＋カタカナ82: 清音46・濁音半濁音25・ッャュョァィゥェォ・ー・ヴ）を KanjiVG から取得します。

`index.html` はデータを `kana-data.js?v=2` のように版番号付きで読み込んでいます。
`kana-data.js`・`stroke-data.js`・`audio/manifest.js` を変えたら、ブラウザに古いファイルが残らないよう `index.html` の `?v=` の数字を1つ上げてください。
